# 🌐 Personal Portfolio Website

This repository contains the code for my personal portfolio site. The site highlights my background in Business Analytics and Information Systems, showcases selected academic and technical projects, and provides quick access to my résumé and contact details. Built with HTML, CSS, Bootstrap, and a touch of JavaScript, the design emphasizes clarity, accessibility, and responsiveness.

## 🧠 Website Overview
- **Homepage (index.html)** with navigation and introduction  
- **Projects Section** linking to detailed project pages  
- **About Me** area with background information and professional photo  
- **Skills** organized into Business, Analytics, and Development categories  
- **Contact** options including Twitter, LinkedIn, and GitHub  
- **Footer** containing links to Privacy, Terms, and Cookie Policy  

### 📂 Project Pages (/projects)
Each project page follows a consistent layout:
- Title banner and summary at the top  
- Written overview describing objectives, data sources, and analysis  
- Embedded PDF report viewable directly in the browser  
- External links to GitHub repos or interactive apps when available  
- Easy navigation back to the main Projects section  

## 🍪 Cookie Consent
The site includes a lightweight cookie consent banner using:
- `cookie-popup.css`  
- `cookie-popup.js`  

Features:
- Appears on first visit  
- Stores consent in browser cookies  
- Meets accessibility and contrast standards  

## 🎯 Purpose
This portfolio was created as part of coursework to demonstrate:
- Clean HTML & CSS structure  
- Responsive layouts with Bootstrap  
- Organized file structure for maintainability  
- Accessibility best practices (contrast, labels, WAVE-compliant buttons)  
- Professional presentation of analytics and business projects  

All files are static and can be opened locally or hosted via GitHub Pages.
